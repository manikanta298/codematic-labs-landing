# Codematic Labs Landing

Build a marketing website for "Codematic Labs," a software development studio, using hatchworks.com as the exact structural and visual reference. Replicate its design language and theme, adapted to our brand.

BRAND
- Name: Codematic Labs
- Tagline: "Building software. Delivering solutions."
- Logo: an abstract mark of two interlocking flame/leaf shapes forming a diamond silhouette, rendered as a smooth blue gradient (light sky blue fading into deep navy blue), sitting on a white circular badge. The wordmark "CODEMATIC LABS" appears in a bold, tracked-out, dark blue sans-serif directly under the mark, with the tagline in small uppercase gray letters beneath that, separated by thin horizontal rules on either side. Recreate this mark as a clean SVG in the navbar logo lockup (icon + wordmark side by side) and use it in the footer too.
- Color palette (derived from the logo gradient): primary blue #1B5FA8, gradient from light blue #4FA8DE to deep navy #0B2545, near-black background #0A0E1A for dark sections, white/off-white #F8FAFC for light sections, muted gray #64748B for secondary text. Use the blue gradient as an accent for buttons, icon badges, and hero background glows — mirroring how hatchworks.com uses a dark hero with a subtle glow/gradient behind bold white headline text.

DESIGN SYSTEM TO MATCH FROM HATCHWORKS.COM
- Sticky top nav: logo left, horizontal menu items with dropdown mega-menus, two CTA buttons on the right (a text link + a solid pill button).
- Hero section: dark navy/black background, large bold headline (mixed weight — key phrase in a different style/italic), supporting paragraph, two CTA buttons (solid pill + outline pill), and a horizontal strip of trusted-client logos below the fold of the hero.
- "Why us" section: light background, 3-column numbered feature cards (01/02/03) with short bold titles and 1–2 sentence descriptions.
- Services/offerings grid: card grid (3 columns desktop) with icon badge, title, short description, and a text link with arrow, each card on a light bordered card with hover lift.
- "Our Method" process section: 3 numbered horizontal steps with icon badges, bold step name, short description, and a bullet list of outcomes, plus a CTA button.
- "How we engage" section: 3-column cards on a dark background describing engagement models.
- Case studies/portfolio carousel: horizontal scroll of project cards with a cover image, category tag, title, and "Read case study" link.
- Testimonials: mix of large pull-quote stat callouts (big bold number + short stat sentence) and headshot-style quote cards in a horizontal scroll.
- Awards/recognition strip: logo badges in a row on a light background.
- Resources section: 3-column content cards (report/newsletter/podcast style) with image, category label, title, and link.
- Footer: dark background, multi-column link groups (Services, What We Deliver, Company, Resources), social icons, office locations, compliance badge, copyright line.
- Typography: bold, modern sans-serif for headings with tight tracking; clean readable sans-serif for body; generous white space; rounded pill-shaped buttons throughout; subtle card hover animations.

CONTENT TO ADAPT FOR CODEMATIC LABS (a full-stack software development & UI/UX studio, not an AI company)
- Hero headline themed around shipping real, working software fast and reliably (not hype).
- Services: Full-Stack Web Development (MERN), UI/UX Design, E-commerce Solutions, Business/Internal Tooling, Mobile Apps, Marketing Websites.
- "Our Method" steps: Discover → Design → Deliver (or similar 3-stage process), each with a short description and outcome bullets.
- "How we engage": Dedicated Development Team, Fixed-Scope Projects, Ongoing Product Partnership.
- Placeholder case studies/portfolio cards for a few representative projects (e-commerce store, café/POS system, community listings app) with generic placeholder names — mark these as placeholder content the client will replace.
- CTA sections: "Talk to our team" / "See our work," linking to a contact section.
- Footer nav should reflect the sections actually built.

Build this as a full, responsive, production-quality multi-section landing page with smooth scroll-based animations and hover states matching the polish level of hatchworks.com. Use placeholder professional stock-style imagery/gradients where hatchworks.com uses photography.
